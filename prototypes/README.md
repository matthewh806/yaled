# Prototypes

Throwaway experiments kept in the repo as primary sources for design decisions. They are **not** built by CMake, not tested, and not part of the plugin.

Each prototype is a single self-contained file: open it in a browser. Each one names the question it was built to answer and the issue it informs.

| Prototype | Question | Issue |
| --- | --- | --- |
| [`crossfade-listening-test.html`](./crossfade-listening-test.html) | Does the fade-to-silence at each Chunk Boundary sound different enough from an overlapping crossfade to matter? | #13 |
