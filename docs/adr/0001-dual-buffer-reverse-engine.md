# Dual-buffer engine with chunk-boundary crossfade for the reverse effect

A naive reverse-delay implementation (fill one buffer, reverse it, play it back, repeat) produces an audible click at every buffer boundary because playback jumps discontinuously between the end and start of consecutive reversed chunks. We chose a dual-buffer design instead: two buffers alternate between "capturing" and "playing back in reverse," swapping roles continuously, with a crossfade applied at each swap to mask the discontinuity. This is more complex than a single-buffer approach but is the standard technique for continuous, glitch-free reverse playback (per prior art discussed on [KVR Audio](https://www.kvraudio.com/forum/viewtopic.php?t=599376)), and it's the foundation the rest of the plugin's parameters (Chunk Length, Tempo Sync, Feedback Path) are built on top of.
