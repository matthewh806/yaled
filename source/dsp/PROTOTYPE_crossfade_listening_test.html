Chunk Boundary Crossfade listening test

The question. Yaled plays each Reverse Chunk backwards, one after another. At every chunk boundary the audio jumps to a different place in the original, which would click. Today the code hides the click by fading each chunk to silence at both ends, so the sound dips at every boundary (ADR-0001 calls this a crossfade, but nothing overlaps). The alternative is a true overlap crossfade: the end of one reversed chunk overlaps the start of the next, so the level stays even.

Does the dip sound audibly worse than the overlap? Does the crossfade length or curve shape matter? Do very short chunks misbehave? Use headphones or decent speakers, click the three buttons while it plays, and try the scenarios below.
